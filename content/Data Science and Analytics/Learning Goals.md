### Long-Term Vision
The goal is to develop a data-driven system that can:

1. Build a history of "problem areas" - roads where violations frequently occur.
2. Simulate realistic datasets and explore transferable algorithms and analysis tools.
3. Eventually experiment with prediction (e.g., linking geography and time of year to likelihood of violations).


### Current Experience
1. No experience with tools like Python, Pandas, Matplotlib, or Jupyter.
2. No experience with core concepts like data cleansing, predictive analytics, time series, or clustering.
3. No access to real data - must simulate realistic datasets.


### Knowledge goals
1. Gain knowledge of data analysis workflows, from data ingestion to visualization.
2. Understand key concepts such as data cleaning, feature extraction, time series, and basic statistics.
3. Learn how data structure and quality affect analysis and predictions.


### Skill goals
1. Learn Python with focus on data science libraries (Pandas, Matplotlib, Seaborn, NumPy).
2. Simulate and structure datasets reflecting real-world data scenarios.
3. Analyze patterns in data and visualize insights effectively.
4. Apply basic prediction techniques using structured data.


### Competencies
1. Integrate advanced data components into complex projects.
2. Independently formulate questions that can be answered with data.
3. Select and apply appropriate tools for structured analysis.
4. Plan and execute analysis pipelines and communicate results clearly.
5. Relate results to broader patterns or use-cases (e.g., urban design, enforcement strategy).
